# JKs Super Dungeon Dish Crawler – Updates

Hier liegen die Downloads der neuesten Version.

- **Windows:** unter [Releases](../../releases/latest) die Datei `…Setup_<Version>.exe` herunterladen und starten. Sie ersetzt die alte Version, der Spielstand bleibt erhalten.
- **Linux:** die Datei `…x86_64.AppImage` herunterladen, ausführbar machen und die alte damit ersetzen.

Das Spiel prüft beim Start die Datei `version.json` und zeigt im Hauptmenü an, wenn es ein Update gibt.
